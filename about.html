I’m a Computer Science and Engineering student who enjoys thinking about how data flows through a system — from the way it is stored to how it appears in the UI. I care a lot about clear structure, predictable behaviour and code that someone else can read six months later without getting confused.

I naturally gravitated towards backend development because I like solving problems around data, APIs and application logic. At the same time, I don’t want my projects to “feel” like backend-only work, so I put effort into keeping the UI clean and friendly enough for non-technical users as well.

Outside the classroom, I’m part of the E-Cell PR team, where I help with event outreach and communication. This pushed me to talk to more people, listen to what they actually need, and then bring that perspective back into the products I build. It’s made me more comfortable presenting, planning and working in small teams.

Looking ahead, I want to keep strengthening my fundamentals in Java, Python and data structures, while slowly moving deeper into distributed systems and AI-assisted development. My ideal work would combine all three: solid backend engineering, clean web experiences and smart use of AI tools to save time.
